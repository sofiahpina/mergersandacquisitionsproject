# After the Deal: Making Mergers Work

A single-page educational website on post-merger integration (PMI): what happens after an M&A deal closes, and why integration is where most of a merger's value is won or lost.

- `index.html` is self-contained (inline CSS and vanilla JS; only Google Fonts is loaded externally).
- To publish on GitHub Pages: Settings → Pages → deploy from branch, root folder.
