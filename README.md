# After the Deal: Making Mergers Work

A single-page educational website on post-merger integration (PMI): what happens after an M&A deal is signed and closed, and why integration is where most of a merger's value is won or lost. Written for business students and early-career professionals.

The site covers why mergers fail, an interactive four-phase integration timeline, the seven pillars of integration, three case studies (Daimler-Benz & Chrysler, AOL & Time Warner, Disney & Pixar), a readiness checklist with a live score, common pitfalls and a glossary.

## Viewing it

- **Locally:** open `index.html` in any modern browser. No build step or server needed.
- **Online:** enable GitHub Pages under *Settings → Pages → Deploy from a branch → `main` / `(root)`*.

## Tech

`index.html` is self-contained: inline CSS and vanilla JavaScript, with Google Fonts (Fraunces and Inter) as the only external resource. It supports light and dark mode and works down to 360px wide.

This is an educational project, not financial or legal advice. `PROMPT.md` contains the brief the site was built from.
